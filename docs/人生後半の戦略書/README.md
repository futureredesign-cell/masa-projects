# 『人生後半の戦略書』校正・典拠化フォルダ

アーサー・C・ブルックス『人生後半の戦略書――ハーバード大教授が教える人生とキャリアを再構築する方法』（木村千里訳、SBクリエイティブ、2023年、ISBN 978-4-8156-1847-6。原書 *From Strength to Strength*, Portfolio, 2022）の OCR テキスト（3,752 行、約 20 万字）を対象に、

1. **校正** … OCR 由来の誤字・字形混同・記号化け・改行ずれ・ページノイズを行番号付きで洗い出し、
2. **典拠化** … 書誌情報の確定、章ごとの主張とその根拠（人物・研究・著作）の対応付け、巻末原注 219 件の整形、

を行った結果をまとめたもの。

## 本文そのものは収録していない

底本は市販の翻訳書であり、全文（校正済み全文を含む）をリポジトリに置くことは複製・公衆送信にあたるため収録していない。本フォルダに入っているのは、

- 書誌情報と章構成（著作物ではない事実情報）
- 校正ログ（誤→正の対応表。文脈は最小限の断片のみ）
- 要点と典拠（**本書の言い回しをなぞらない**独自の要約と、典拠の索引）
- 原注の整形版（書誌データ）
- 校正ログを手元の OCR テキストに適用するスクリプト

である。校正済みの全文が必要な場合は、手元の OCR テキストに `scripts/apply_corrections.py` を適用してローカルで生成する（下記）。

## 行番号について

すべてのファイルで使う「行」は、底本 OCR テキスト（アップロード時のファイル）の **1 始まりの行番号** で統一している。章ごとの行範囲は `00_書誌情報.md` の「構成」表を参照。

## 校正ログの読み方

各行は `| 行 | 誤 | 正 | 種別 | 確度 | 備考 |`。

- 種別: `誤字(OCR)` / `字形混同` / `記号・句読点` / `改行ずれ` / `ノイズ` / `表記ゆれ` / `欠落・重複`
- 確度: `高`（明らかな誤り）/ `中`（文脈上ほぼ確実）/ `低`（原本での確認が必要）

「改行ずれ」「ノイズ」の一部は、修正内容が「見出しを独立行に」「削除」のような操作指示になっている。これらはスクリプトでは自動適用せず、人手で行う前提。

## 修正をローカルで適用する

```bash
python3 docs/人生後半の戦略書/scripts/apply_corrections.py \
  --source /path/to/ocr.txt \
  --out    /path/to/ocr_corrected.txt \
  --confidence 中
```

- `--confidence` は `高`（既定）/ `中` / `低`。指定した確度以上の行を適用する。
- 行番号で位置を特定し、その行に「誤」の文字列が存在する場合だけ置換する。見つからなかった修正は `*.report.md` に一覧で出力される。
- `--no-global` を付けると、全文に対する安全な語置換（「日標」→「目標」、「研先」→「研究」など文脈に依存しないもの）と、原注部分の全角記号を半角化する一括ルールを無効にする。
- 参考値（底本 OCR テキストに `--confidence 中` で適用した場合）: 校正ログ約 1,070 行のうち約 800 件を自動適用、約 160 件は見出しの独立行化などの操作指示のため人手対応、約 20 件は省略表記のため行内で一致せず未適用（レポートに一覧）、全角記号の半角化は約 780 箇所。
- 段落の入れ替わり（第2章 752–768、第4章 1454–1463、第5章 1865–1877、第6章 1936–1940・2138–2153・2387–2401、第7章 2556–2570、第9章 3464–3467、おわりに 3600・3629–3631）はスクリプトでは直らない。各章の校正ログに復元手順を記載している。

## 典拠化の方針

- 「主張と典拠」表は、本文中の主張を独自の言葉で要約し、その根拠として本文が挙げる人物・研究・著作・データを列挙、巻末原注の番号と突き合わせた。対応が確実でないものには `?` を付けている。
- 本文中に根拠として現れるが原注にないもの（著者の体験談、取材対象者など）は原注番号を `—` とし「本文のみ」と明記した。
- 原注の英文書誌は、OCR 誤りを修正し全角記号を半角に統一した。確信の持てない修正には `[?]` を付した。一部は Web で論文題名・誌名を確認済み（校正ログの備考に「Web確認済」）。
- 本文の数値や帰属が原注と食い違う箇所（例: 第6章 2230 の UCLA 帰属、第2章 671 の年齢、第9章 3439 の生存率）は、OCR 誤りか底本・原書由来かを判別できないため、要点ファイルと総括に「要原本確認」として残した。
