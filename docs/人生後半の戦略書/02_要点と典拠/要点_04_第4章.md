# 第4章 欲や執着を削る――死ぬまで足し算を続ける生き方をやめる / Start Chipping Away（全体行 1141–1637）

## 節構成

- バケットリスト
- 王子から聖人になった者たち
- 満足の科学
- 進化の仕組みに紛れ込んだバグ
- 方程式を修正する
- 1. WHATではなくWHYを問う
- 2. リバースバケットリスト
- 3. 「小さく」生きる
- 先を見据える

## 要旨

著者は台北の故宮博物院でガイドから聞いた「西洋は白紙に足して芸術を作り、東洋は翡翠の塊から余計な部分を削って芸術を現す」という対比を、人生後半の生き方の比喩として据える。西洋的な成功観は財産・業績・人脈・経験を積み上げ続ける「バケットリスト」型だが、著者が知る大富豪の起業家のように、集めれば集めるほど満たされない。対照的に、貴族の家を捨てて托鉢修道士になったトマス・アクィナスと、王宮を出て苦行の末に中道を悟った釈迦は、世俗的な見返り（金・権力・快楽・名誉）への執着を削ることで本来の自己に至った。現代科学もこれを裏づける。ホメオスタシスにより快感はすぐ中和され（快楽のランニングマシン）、社会的比較と損失回避の本能が「他人より多く持ち続ける」「減らさない」ことを強いるため、ドーパミン的な短期快楽は得られても持続する満足には至らない。著者は「満足＝持っているもの÷欲しいもの」という式を提示し、分母である欲望の管理こそ鍵だと述べる。実践法として、(1) WHAT（肩書き・活動）ではなくWHY（目的）を問い、目的に資さないものを削る、(2) 毎年誕生日に自分の欲を書き出し、5年後の幸福な自分の姿と照らして手放す「リバースバケットリスト」、(3) 皿洗いや夜に開く花のような小さな事柄に注意を向けて生きる、の3つを挙げる。最後に、バケットリストにも時間の有限性を意識させる効用があることを認め、次章の主題である「終わりを見据えた計画」へつなぐ。
