# 第5章 死の現実を見つめる――必ずある終わりを受け入れる / Ponder Your Death（全体行 1638–1879）

## 節構成
- 死の恐怖を理解する
- 本当に永遠に粘り続けたいですか？
- レガシーについての正しい考え方
- 落ち込みに真っ向から向き合う
- 死と落ち込みの大きな違い

## 要旨
著者は、仕事を自分の存在証明にしているストライバーにとって、キャリアの落ち込み（流動性知能の低下）は「職業上の死」であり、それへの恐怖は実際の死への恐怖と本質的に同じだと論じる。限界まで働き続けて逃げ切ろうとする「抵抗作戦」は寿命に逆らえないのと同様に成立せず、第2の曲線に乗り換えるには、まず死と落ち込みという現実を直視する必要がある。
前半では、死の恐怖の中でも「存在しなくなる恐怖」が人間固有のものであり、落ち込みへの恐怖はまさにこれだと整理し、死と失墜をともに極度に恐れたウォルト・ディズニーを例に挙げる。次いで、老いながら死ねないストラルドブラグ（『ガリバー旅行記』）を「職場で粘り続ける人」の比喩とし、不朽の名声を選んだアキレスを引いて、レガシーで忘却を回避する戦略も結局は無駄だと述べる。
後半では、デイヴィッド・ブルックスの「履歴書向きの美徳」と「追悼文向きの美徳」の区別を借り、後者は年齢とともに伸ばせるうえ人生の充実にも直結すると説く。そのうえで、恐怖症治療の曝露療法（脱感作）の考え方を死と落ち込みに応用し、死を具体的に想像するほど恐怖は薄れるという研究やモンテーニュ、仏教の死随念（マラナサティ）の実践を紹介。著者自身は落ち込みの9段階を思い描く瞑想を行っているという。最後に、死は一人で迎えるが落ち込みは一人で迎える必要がない点が両者の決定的な違いだとして、人間関係を扱う次章へつなぐ。
