# 第2章 第2の曲線を知る――流動性知能から結晶性知能へシフトチェンジする / The Second Curve（全体行 475–774）

## 節構成
- 2つの知能
- 第2の曲線の喜び
- バッハのようにあれ
- 第2の曲線に飛び乗る

## 要旨
第1章で示した中年期の能力低下の裏側に、加齢とともに伸びる別の能力があることを論じる章。語彙力や複数の概念を統合・解釈する力は高齢ほど高まり、応用数学者や歴史家のように既存知識の組み合わせを武器とする職業ではピークが大幅に遅れる。著者はこれを心理学者レイモンド・キャッテルの二つの知能で説明する。新しい問題を素早く解く「流動性知能」は成人初期に頂点を迎え30～40代で衰えるが、蓄積した知識を使いこなす「結晶性知能」は中年以降も上昇を続ける。第1章の生産性曲線は実質的に前者であり、その背後に第2の曲線が隠れている（図2）。革新者から教師・助言者へ役割を移せば落ち込みは先送りでき、仕事の価値はむしろ高まる。根拠として高齢教授の授業評価、晩年の助言と教育を説いたキケロ、若手偏重のテック業界の失敗が挙げられる。中心に置かれるのはJ・S・バッハの生涯で、息子C・P・E・バッハの古典派に押されて時代遅れとなった父は、失意のダーウィンとは対照的に教本『フーガの技法』を書く教育者として自らを再定義し、満ち足りた晩年を送った。最後に移行を妨げる三つの足かせと助けとなる三つの実践を予告する。
